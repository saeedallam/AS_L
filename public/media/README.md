# صور الموقع

ضع صور المنتجات هنا بالأسماء التالية، والموقع هيعرضها تلقائيًا من غير أي تعديل في الكود.
الامتدادات المدعومة: `.avif` `.webp` `.jpg` `.jpeg` `.png` (الأفضلية بهذا الترتيب).

| اسم الملف | مكانه في الصفحة | المقاس المقترح |
| --- | --- | --- |
| `hero` | الصورة الرئيسية في الأعلى | 1200×900 |
| `cat-bags` | بطاقة "مستلزمات مدرسية" | 800×600 |
| `cat-art` | بطاقة "أدوات فنية" | 800×600 |
| `cat-notebooks` | بطاقة "دفاتر ومفكرات" | 800×600 |
| `cat-office` | بطاقة "أدوات مكتبية" | 800×600 |
| `p-notebook` | منتج: مفكرة | 800×800 |
| `p-pen` | منتج: قلم | 800×800 |
| `p-case` | منتج: مقلمة | 800×800 |
| `p-backpack` | منتج: حقيبة | 800×800 |
| `brand-1` … `brand-4` | بطاقات العلامات التجارية | 800×640 |
| `gallery-1` … `gallery-5` | معرض الصور | 800×800 |

مثال: `public/media/hero.jpg`

نصائح للتصوير: خلفية فاتحة وموحّدة، إضاءة طبيعية، والمنتج في منتصف الكادر.

## صور الكتالوج

صفحة «كل المستلزمات» فيها ١٨ منتج تجريبي، كل واحد له خانة صورة من `c-1`
لحد `c-18`، بنفس الترتيب الظاهر في الصفحة. حطّ الصورة باسم الخانة، مثلًا
`c-1.jpg`، والمقاس المناسب ٨٠٠×٨٠٠ بكسل (مربّعة).

| الخانة | المنتج |
| --- | --- |
| `c-1` | حقيبة ظهر مدرسية |
| `c-2` | حقيبة بعجل |
| `c-3` | مقلمة قماش |
| `c-4` | كشكول سلك A4 ‏١٠٠ ورقة |
| `c-5` | مفكرة جلدية A5 |
| `c-6` | كراسة ٦٠ ورقة |
| `c-7` | قلم جاف أزرق |
| `c-8` | قلم حبر معدني |
| `c-9` | طقم أقلام رصاص |
| `c-10` | طقم أدوات هندسية |
| `c-11` | مسطرة ٣٠ سم |
| `c-12` | ألوان خشبية ٢٤ لون |
| `c-13` | ألوان مائية ١٢ لون |
| `c-14` | كراسة رسم A3 |
| `c-15` | دبّاسة مكتب |
| `c-16` | آلة حاسبة علمية |
| `c-17` | منظّم مكتب |
| `c-18` | ورق تصوير A4 |

## خانات الأقسام

الأقسام الستة بتستخدم الخانات دي:

`cat-bags` · `cat-notebooks` · `cat-pens` · `cat-geometry` · `cat-art` ·
`cat-office`

المقاس المناسب ١٢٠٠×٩٠٠ بكسل.
