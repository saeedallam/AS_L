# صور الموقع

ضع صور المنتجات هنا بالأسماء التالية، والموقع هيعرضها تلقائيًا من غير أي تعديل في الكود.
الامتدادات المدعومة: `.avif` `.webp` `.jpg` `.jpeg` `.png` (الأفضلية بهذا الترتيب).

| اسم الملف | مكانه في الصفحة | المقاس المقترح |
| --- | --- | --- |
| `hero` | الصورة الرئيسية في الأعلى | 1200×900 |
| `cat-school` | بطاقة "مستلزمات مدرسية" | 800×600 |
| `cat-art` | بطاقة "أدوات فنية" | 800×600 |
| `cat-notebooks` | بطاقة "دفاتر ومفكرات" | 800×600 |
| `cat-office` | بطاقة "أدوات مكتبية" | 800×600 |
| `p-notebook` | منتج: مفكرة | 800×800 |
| `p-pen` | منتج: قلم | 800×800 |
| `p-case` | منتج: مقلمة | 800×800 |
| `p-backpack` | منتج: حقيبة | 800×800 |
| `brand-1` … `brand-4` | بطاقات العلامات التجارية | 800×640 |
| `gallery-1` … `gallery-5` | معرض الصور | 800×800 |

مثال: `public/media/hero.jpg`

نصائح للتصوير: خلفية فاتحة وموحّدة، إضاءة طبيعية، والمنتج في منتصف الكادر.
